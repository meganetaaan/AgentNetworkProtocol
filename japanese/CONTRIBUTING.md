# 貢献ガイド

本プロジェクトに関心をお寄せいただきありがとうございます。コミュニティからの貢献を歓迎します。

## 貢献できる方

次のような方々の参加を歓迎します。

- ネットワーク技術を研究している開発者
- プロトコルの設計と実装に関心があるエンジニア
- 関連ソフトウェアを開発している企業
- 大学や研究機関の研究者
- その他、本プロジェクトに関心がある貢献者

## 貢献の手順

### 1. 事前の議論

文書を書き始める前に、次のことをお勧めします。

- GitHub Issuesでアイデアを提案する
- Discordコミュニティで他の開発者と議論する
- 案の実現可能性を確認するため、コミュニティから十分な意見を集める

### 2. プルリクエストの提出

- 文書がプロジェクトの基準に適合することを確認してください。
- 変更の目的と実現方法を説明する、明確なPR説明を付けてください。
- 関連するIssueがある場合は、説明で言及してください。

### 3. 文書レビュー

- PRをできる限り速やかにレビューします。
- 必要に応じて、関連分野の開発者を議論に招待します。
- 修正や改善をお願いする場合があります。
