## 謝辞

Agent Network Protocol プロジェクトに貢献してくださった皆様に心より感謝いたします。規模の大小を問わず、あらゆる貢献が、エージェント ネットワークの時代に合わせて HTTP を構築するという私たちの使命を前進させるのに役立ちます。
