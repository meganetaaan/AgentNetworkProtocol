元のノードID、接続、HTTPヘッダー、プロトコルの例は保持し、人が読むラベルを日本語にしました。元ファイルは変更していません。

- [非対称暗号の図](blogs/images/asymmetric-encryption.ja.mmd): [原文](../../../blogs/images/asymmetric-encryption.mmd)。アイデンティティ所有者、署名、検証の全ラベルを翻訳。

認証フローは旧方式を示す歴史資料です。現行ANP-02のHTTPメッセージ署名へ書き換えた図ではありません。
