# W3C AI Agent Protocol Community Groupの最新の進捗（2025年6月）

エージェント通信プロトコルの標準化を進めるため、ANP（Agent Network Protocol）のオープンソースコミュニティは、W3CでAI Agent Protocol Community Groupの設立を主導しました。この記事では、このコミュニティグループの最新の進捗を詳しく紹介します。

コミュニティグループは、2025年6月18日に最初の会議を開きました。主に、グループの目標、活動範囲、会議の進め方、今後の計画について議論しました。

議事録：https://github.com/w3c-cg/ai-agent-protocol/blob/main/meetings/2025-06-18.md

## コミュニティグループの背景と構成

W3C AI Agent Protocol Community Groupは、ANPのオープンソースコミュニティがW3Cで設立を提案し、立ち上げたもので、エージェント通信プロトコルの標準化を推進することを目的としています。ANPコミュニティの創設者であるChang Gaoweiが共同議長を務め、関連する活動の調整と推進を担当しています。

現在、このコミュニティグループには、国内外の多くの著名な企業や学術機関が参加しています。例えば、次のような組織です。

**学術機関：**

これらのメンバーの参加によって、コミュニティグループは、強力な技術支援と産業界の資源を得ています。エージェントプロトコルの標準化に、世界中から幅広い関心が寄せられていることを示しています。

## コミュニティグループの使命と活動範囲

### 使命

AI Agent Protocol Community Groupの使命は、エージェントがインターネット上で効率よく相互に発見し、接続し、協働できる、オープンで相互運用可能なプロトコルを開発することです。エージェントがインターネット上の活動に関わる機会が増えるにつれ、安全で信頼でき、拡張可能なやり取りを支える標準化された仕組みが、ますます必要になっています。この組織は、新たに生まれつつある「Agentic Web」の技術基盤を確立することを目指しています。

### 活動範囲

コミュニティグループは、次の重要な領域を検討し、定義します。

**1. エージェント間の通信プロトコル**
- エージェント同士が相互に発見できる仕組みを確立する。
- 意図や能力に関する情報を交換する。
- 役割分担を交渉する。
- オープンなWeb環境で、協働関係を動的に構築したり解消したりする。

**2. エージェントのアイデンティティモデル**
- オープンな標準に基づくAIエージェントのアイデンティティの枠組み。
- ドメインの異なるエージェント同士の、安全で相互運用可能な認証を支える。

**3. 標準化されたメタデータ形式**
- エージェントの能力、インターフェース、目標、状態を構造的に記述する。
- Webに自然に適した形式を基盤とし、エージェントの行動に関する自動推論、組み合わせ、調整を支える。

**4. セキュリティとプライバシーの仕組み**
- ドメインをまたぐエージェント通信のセキュリティモデル。
- 検証可能な資格情報に基づく本人確認、認可、信頼の仕組み。
- エージェント間のやり取りの完全性と機密性を守る、エンドツーエンド暗号化。

**5. プロトコル間の相互運用性**
- エージェントを基盤とするシステムが、既存のWebプロトコルと標準を使って統合し、協働できるようにする。

コミュニティグループは、関連する技術仕様を公開します。また、信頼できる、協働可能なエージェントのWebエコシステムを構築するため、AIプラットフォームの開発者、プロトコルの設計者、ブラウザーのベンダー、Webアプリケーションの開発者、学術研究者など、オープンな標準の推進に関心のある関係者の参加を歓迎しています。

## 主な成果物

コミュニティグループは、すでに二つの重要な技術文書を作成しています。

### 1. Agent Network Protocolホワイトペーパー草案
**文書：** https://w3c-cg.github.io/ai-agent-protocol/

このホワイトペーパーは、エージェントネットワークプロトコルの技術的な背景、発展の傾向、標準化の必要性について詳しく説明しています。エージェント技術の発展の現状、直面する課題、今後の発展の方向性を扱っています。

### 2. エージェントプロトコル技術仕様の枠組みの草案
**文書：** https://w3c-cg.github.io/ai-agent-protocol/protocol.html

この技術的な枠組みは、エージェントプロトコルの具体的な実装方式に関する主要なモジュールを、詳しく定義します。内容には、次が含まれます。
- エージェントの本人認証の仕組み。
- エージェントの発見と記述のプロトコル。
- エージェント間の通信の標準。
- セキュリティとプライバシーを保護する仕組み。
- プロトコル間の相互運用性の設計。
