# Agentic Web の違い

エージェントは本質的に、AI 業界の**コンセンサス** となっています。意見の相違がある場合、それはおそらく実装のスケジュールに関するものです。現在、業界は主にエージェント自体を構築する方法に焦点を当てており、エージェントがどのように連携するかやエージェント ネットワークの特性に関する研究はあまり行われていません。

この記事では、インターネットの進化の本質、**新しいテクノロジーの機能を解き放つ**の観点から、エージェントティック Web と既存のインターネットの違いを探ることを試みます。

私たちは、エージェントがソフトウェア自体に重大な変更をもたらすだけでなく、インターネットにも **重大な変更** をもたらすと信じています。

現在の世界的なインターネット市場規模を考慮すると、Agentic Web の違いを理解するのは少なくとも 1,000 億ドルかかる問題です。

重要なポイント:

- インターネットの進化における最も基本的な問題は、**新しいテクノロジーの可能性**を最大限に活かす方法です。 AI技術の発展により、次世代のインターネットは間違いなく大きく変化するでしょう。
-  AI の機能を解放するには、AI が完全なコンテキスト情報にアクセスし、インターネット上で利用可能なすべてのツールを活用し、最も熟練した方法でインターネットと対話し、インターネット上の他の AI と効率的に連携できるようにする必要があります。
- これを達成するには、**相互接続**、**ネイティブインターフェース**、**効率的なコラボレーション**の3つの問題を解決する必要があります。
- API または通信プロトコルは、AI がインターネットと対話するための最適な方法です。私たちは、AI が人間を模倣するコンピューター使用テクノロジーについては楽観的ではありません。 AI フォンは、端末上のさまざまなアプリを統合するためのソリューションを提供します。 Anthropic の MCP は私たちのビジョンと最も一致しています。
- **パーソナル アシスタント** は、エージェントがインターネットの隅々に浸透し、次世代インターネットへの新しいゲートウェイとなるでしょう。これらのエージェントは、相互接続、自己組織化、および自己ネゴシエーションを行って、効率的な共同ネットワークを構築できます。
- 私たちはエージェント通信用のオープンソース プロトコルである AgentNetworkProtocol (ANP) を開発しており、Agentic Web 時代の HTTP を目指しています。

## インターネット進化の基本的な推進力は何ですか?

私たちは、最も根本的な問題、つまりインターネットの進化を推進する根本的な力は、どのように **新しいテクノロジー** の機能を解き放つかであると信じています。

質問を分析してみましょう。なぜ PC インターネット時代には Web ベースの製品が主流だったのに対し、モバイル インターネット時代にはアプリが主流だったのでしょうか?

PCインターネット時代の新技術は、主にネットワーク通信技術（TCP/IP、DNS、HTTP）、Web技術（HTML、CSS、JavaScript）、データベース技術、情報検索技術で構成されていました。ブラウザと Web テクノロジを介した製品フォームにより、オープン インターネット アクセスの力が解放され、統一されたエントリ ポイントを通じて情報に広くアクセスできるようになりました。

当時の技術的条件 (限られた帯域幅とハードウェア パフォーマンス) と Web テクノロジのクロスプラットフォームの性質を組み合わせることで、Web が PC インターネットに最適な製品形式であると判断されました。

モバイル インターネット時代の新しいテクノロジーには、モバイル デバイスとハードウェア (加速度計、ジャイロスコープ、GPS、タッチスクリーン、カメラ、チップ)、モバイル ネットワーク (3G、4G、5G)、モバイル オペレーティング システム (iOS、Android) が含まれていました。

Web テクノロジーと比較して、アプリはオペレーティング システム API を通じてハードウェア機能を深く統合し、デバイスのパフォーマンスに合わせて実行効率を最適化し、リアルタイムの対話により継続的なオンライン プレゼンスを維持できます。

これらの要因により、アプリを通じて新しい技術機能が解き放たれ、アプリのユーザー エクスペリエンスが Web よりもはるかに優れたものとなり、モバイル インターネット時代の主流の製品形式になりました。

現行の10年で、新しい技術は、遺伝子知能、大言語モデル、エージェントによって間違いなく表現されています。 AIの機能を解き放つ方法は、将来のインターネットの進化の方向を決定します。

## 次世代インターネットがAIの能力を解明すべきこと

現在のインターネットインフラは、かなり総合的ですが、その特徴を与えられたAIの能力を十分に解明してもまだ課題があります。

### AIをAIに提供する方法 **完全なコンテキスト情報** へのアクセス **すべてのツールの機能**

AIは、完全なコンテキスト情報で正しい決定を下すことができるだけ。 複雑なタスクを効率的に完了できるので、すべてのツール機能にアクセスすることができます。

しかし、インターネットは基本的に情報サイロから構成され、それらの間に困難な情報の流れを伴います。

  <img src="../../blogs/images/data-silos.png" width="50%" alt="data-silos"/>
</p>

以前は、ブラウザ、アプリ、検索エンジン、ソーシャルネットワークを通じてこれらの情報サイロを接続する役割を担っている。 今後、AIでより効率的に実施される予定です。

現在の技術ソリューションは、AI電話やコンピュータ利用技術により、インターネットに接続できるAIがグラフィカルインターフェイス、ブラウザ、またはアプリ端末インターフェースを介してインターネットに接続できるようにするという点で、これらの問題に対処することを試みています。 しかし、これらは最も効率的なソリューションではないと確信しています。

### 人工知能がインターネットと最も有能な方法でインターフェイスさせる方法

AIのインターネットアクセスに関する最新のソリューションを評価しましょう。

1. **コンピュータ利用技術**

多くのモデルプロバイダは、同様のソリューションを開始しました。

<p align="center">
  <img src="../../blogs/images/computer-use-product.png" width="50%" alt="computer-use-product"/>
</p>

しかし、この技術について最適化するものではありません。 既存のインターネット製品が人間用に設計されていて、AIが学習し、人体を模倣するAIがインターネットにアクセスするための最も簡単な道である前に、これらの製品はAIのために再構成されているため、出ました。 しかし、それは最も効率的なパスではありません。 短期・中期の期間に値がかかることがありますが、長期間の値が限られている可能性があります。

2. **AI電話ソリューション**

Apple Intelligenceなどの国内電話メーカーも多く、大幅な普及を進めています。

これらの技術は、端末上のアプリクライアントが開いたインターフェースを介してインターネットデータと機能にアクセスすることで特徴付けられます。 これにより、複数のアプリから複数のアプリやインボケ機能からデータを取得できます。

この技術は、コンピュータ利用のテクノロジーよりも一歩進んでいます。AIは、グラフィックインターフェイスではなく、データを処理する際に自然に優れています。 しかし、このソリューションでは、端末アプリは、AI電話と競争的かつ協力的な双方の厄介な立場にあり、AI電話からトラフィックを獲得したいという思いで、AI電話に置き換えることを避けるためにあまりにも多くのデータを開くことを望んでいます。

3. **クラウデ MCP**

現在、ビジョンとベストを合わせるソリューションです。

わたしたちは、 **AIは、グラフィックインターフェイスではなく、データを処理する方が優れているという人間のものと異なり**. . . AIは、最も有能な方法でインターネットとやり取りする必要があります()**API または通信プロトコル**).

同様のプロジェクトや研究を早期に進めています。 [代理店ネットワークの議定書の技術の白いペーパー](https://mp.weixin.qq.com/s/17pNcvi1klEwuqDrEbLzJw).

MCP のメインの違いは、世界観です。
- MCPは、インターネット全体がコンテキストとツールとして機能するモデル中心です。
- エージェント・ネットワーク・プロトコルは、各エージェントが同じステータスを持ち、分散型のエージェント・コラボレーション・ネットワークを形成するエージェント・セントリックです。

### インターネット上でAI間で効率的なコラボレーションを有効にする方法

従来のネットワークノードは、ハードコードやマニュアルメソッドで接続します。 AI、ネットワーク接続、コラボレーションの手法により、より効率的な運用が可能になりました。

例えば、AI ノードは自然言語の生成と理解能力を最初に通信し、自然な言語でインターフェイスを通信するために使用することができ、2 つの AI ノードは通信およびコラボレーションのための標準的なプロトコルまたはコンセンサスプロトコルを使用します。

より効率的な低コストのコラボレーションネットワークを構築するのに役立ちます。

  <img src="../../blogs/images/meta-protocol-flow.png" width="50%" alt="meta-protocol"/>
</p>

最後に、インターネットが完全に削除するAIの機能に要約するために、3つの問題は解決する必要があります。

- 🌐 **相互接続性**: エージェントが互いにやり取りし、データをシャシロに分割し、AIが完全なコンテキスト情報を取得でき、インターネット上のすべてのツールにアクセスできるようにします。
- 🖥️ **ネイティブインターフェイス**: AIは、インターネットにアクセスするために人間を模倣する必要はありません。最も有能な方法でインターネットとやり取りする必要があります(APIや通信プロトコル)。
- 🤝 **効率的なコラボレーション**:AIを利用することで、エージェントは自己組織化し、自負できるようになり、既存のインターネットよりも費用効果が高く効率的なコラボレーションネットワークを構築することができます。

## エージェントWebはどのようなものがありますか?

有能なWebを定義することは重要な提案であり、学術的に厳しい定義を提供できません。 しかし、私たちは共通の視点から理解を説明することができます。 象に触れる盲目の男性のようなものです。私たちは「手伝い」をしている部分を記述しています。

1. **エージェントが新しいゲートウェイになる**

PCインターネット時代は、PCをオンラインで行くために使用している人々についてありました。モバイルインターネット時代は、モバイルデバイスを使用してオンラインに行く人についてでした。 エージェントのWeb時代は、人々を代わってオンラインに行き、デジタルの世界とやり取りするエージェントについてです。

将来的には、スーパーパーソナルアシスタントのエージェントの特別なタイプになる可能性があります。 人体を代えてオンライン上で、クライアント側でパーソナライズされたUIを通じて人間とやり取りします。 バックエンドでは、APIやプロトコルを介して他のエージェントとやり取りします。

<p align="center">
  <img src="../../blogs/images/user-agent-internet.png" width="50%" alt="user-agent-internet"/>
</p>

2. **エージェントはインターネットのあらゆるコーナーを浸透させます**

パーソナルアシスタント以外にも、ホテルやレストラン、銀行、学校のエージェントなどエンドユーザーと直接やり取りしないインターネットには多くの代理店がいます。 人身のアシスタントとのやり取りを通じて、人と間接的にサービスを提供します。

3. **エージェントは相互接続できます**

どの会社やプラットフォームに所属しているかにかかわらず、個人アシスタントやバックエンドサービスエージェントであっても、相互接続が可能です。

4. **フラットターネットワーク**

エージェントがインターネット上で接続して連携するノードとして人や団体を表すことができる場合、集中型プラットフォーム(WeChat、淘宝)の役割は減少します。 未来のインターネットは、より平坦で分散化されます。

5. **自己組織と自己交渉の効率的なコラボレーションネットワーク**

エージェントは、自己組織化とセルフネゴティエートをすることで、効率的なコラボレーションネットワークを構築することができます。

## インフォメーション

最終的には、インターネットの進化を促す技術開発であり、新たな技術能力を解明する方法は、インターネットの進化の方向性を決めるという技術の開発だと確信しています。

エージェントWebが出現してもまだ特定のわけではありませんが、AI技術の発展により今後のインターネットが高度に変化する可能性があると確信しています。
