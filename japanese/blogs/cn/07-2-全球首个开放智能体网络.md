# AI はもはや孤島ではありません: 1 つのプロトコルを使用して世界中のインテリジェント エージェントを接続します

##  「アプリ島」に別れを告げ、AI ネイティブのインターネットを歓迎します

次のシナリオを想像してください。

** 過去 20 年間、私たちは次のような運用に慣れてきました: **
あなたは上海に旅行したいと考えています。ブラウザを開いてガイドを検索し、天気アプリを開いて天気を確認し、Ctrip を開いてホテルを予約し、12306 を開いて高速鉄道のチケットを購入します...異なるアプリ間でジャンプしてコピー アンド ペーストを繰り返します。

**そしてエージェント ネットワークの将来では、すべてが次のようになります: **
あなたがしなければならないのは、AI アシスタントに「来週の上海への旅行の計画を手伝ってください」と言うだけです。
** では、** ではアプリをダウンロードできませんが、バックグラウンドで直接ダウンロードできます。
*   は**気象情報局**に質問し、週末が晴れであることを確認しました。
*   は**ホテルインテリジェント**に電話し、外灘リバービュールームの鍵を閉めました。
*   は**高速鉄道インテリジェントボディ**に接続し、チケットの購入を完了します。

数秒以内にすべてが完了します。

これはSF映画ではなく、**Open Agent Network(オープンエージェントネットワーク)**が実現されている現在の瞬間です。

## なぜ AI は今日でも「島」なのでしょうか?

AI の爆発的な発展に伴い、今日、私たちは最も賢い「頭脳」 (大型モデル) に加え、スーパー ポータルを目指すさまざまなアシスタント (ChatGPT、Claude、Gemini、Doubao、Qianwen、kimi など) を持っています。

しかし、彼らは皆、同じ恥ずかしい現実に直面しています。**AI は非常に強力ですが、インターネットは「弱すぎる」のです。 **

1.  **プラットフォームが閉じられました **: アシスタントは別のプラットフォームからアプリケーションを呼び出すことができません。
2.  **サービスの断片化**: AI はチケットの予約やテイクアウトの注文を支援するためにアプリの壁を越えることはできません。
3.  **分散アイデンティティ**: 各プラットフォームにアカウントを登録する必要があり、AI についても同様です。

**これらの島の効果は次のことにつながります。私たちは超知能を持っていますが、それをチャットにのみ使用できます。 **


# **オープンエージェントネットワークの3つのコア機能**

オープン エージェント ネットワーク (OAN) を使用すると、すべてのエージェントがオープン プロトコル (ANP など) を通じて 3 つの主要な基本機能を取得できます。

## **① 無料ディスカバリー（ディスカバリー） **

Web サイトと同様に、各エージェントには独自の「ドメイン名エントリ」があります。
どのエージェントも任意のエージェントを見つけることができます。

## **② 自己記述（説明） **

各エージェントは「エージェントの説明」を提供します。
私が誰であるか、私に何ができるか、そして私が提供するインターフェースを他の人に伝えてください。

## **③ 双方向インタラクション (Interaction) **

エージェントは自然言語で通信し、OpenAPI や JSON-RPC などの構造化された方法で互いのインターフェイスを呼び出すことができます。

さらに、すべての通信は暗号化され、分散エージェント ID スキーム (ANP の DID スキームなど) に基づいて認証されます。
これは次のことを意味します。

* プラットフォームごとにアカウントを作成する必要はなく、1 つのアカウントで世界中をカバーします
* クロスプラットフォーム通話はもはや問題ではなく、すべてのエージェントの相互接続が実現します

**これは AI の HTTP モーメントです。 **

## 解決策: オープン エージェント ネットワーク (OAN) とは何ですか?

このジレンマを打破するために、私たちは **世界初のオープン エージェント ネットワーク ** を構築しました。

簡単に言うと、**数千の Web ページを接続し、World Wide Web を構築する HTTP プロトコルと同じです。 ANP (Agent Network Protocol) を使用して世界中のエージェントを接続し、AI 時代のインターネットを構築したいと考えています。 **

### これにより、次の 3 つの破壊的な変化がもたらされます。

1.  **エージェントフリー接続サービス**:
パーソナル アシスタント (需要側) は、ホテル、レストラン、教育機関などのサービス エージェント (供給側) に直接接続して、問い合わせから取引までのプロセス全体を完了できます。
2.  **エージェント間の協力**:
「スケジュール管理アシスタント」は「健康アシスタント」に、あなたが最近疲れすぎていることを伝え、重要でない会議をキャンセルするのを自動的に支援します。
3.  ** 誰でも ** にアクセスできます:
企業でも個人の開発者でも、プロトコルをサポートしていれば、このグローバル ネットワークに参加できます。

> ** 開発者向け **: 一度開発すれば、世界中のすべてのエージェントに接続できます (一度書いて全員に接続)。
> ** ユーザー ** へ: 1 人のアシスタント、すべてのサービス (1 人のエージェント、すべてのサービス)。

## なぜ「プラットフォーム」ではなく「プロトコル」でなければならないのですか?

これが既存のエージェントプラットフォームとの最大の違いです。

ほとんどのプラットフォームは、「私の SDK を私の領域で使用し、私のルールに従ってください」と指示します。 (これは、Apple App Store と同じように、**Platform Thinking** です)。

私たちはこう言いました。「Python を使用しているか Go を使用しているかに関係なく、AWS にいてもローカル コンピューターにいても、『共通言語』を話せる限り、会話は可能です。」 (これは、World Wide Web のような、**プロトコル思考** です)。

*   ** プラットフォームは「土地を借りて家を建てる」**: 家賃が値上がりし、ルールが変わり、抵抗できません。
*   ** 契約は「土地を取得して家を建てる」です **: あなたのエージェントは常にあなたのものになります。

**ANP (エージェント ネットワーク プロトコル) の中心理念: **
*   🔓 **ロックインの拒否 **: 単一のベンダーやプラットフォームに依存しません。
*   🚀 **テクノロジーに依存しない **: LangChain、AutoGPT、または任意の自社開発アーキテクチャと互換性があります。
*   🤝 **生態学的繁栄 **: プロトコルはインフラストラクチャであり、上位層のアプリケーションは無限に成長できます。

## ANP を使用する理由

ANP は、**インターネット コラボレーション** のために特別に設計された世界初のオープンソース プロトコルです。

**他のプロトコルとの最大の違いは「アイデンティティ」です。 **

当社では、**DID (分散型アイデンティティ) ** テクノロジーを使用しています。これにより、エージェントには **Email** と同じ自由度が与えられます。
*   **壁を壊す**: 相手がどのサービスプロバイダーを使用していても、直接通話できます。
*   **相互接続**: アカウント登録を繰り返す必要がなく、ネットワーク全体で 1 つの ID を使用できます。

他のほとんどのプロトコルでは、エージェントは「ローカル エリア ネットワーク」でのプレイのみを許可されますが、ANP では、エージェントが実際に **インターネット** に入ることができます。

## ミニマリスト建築: どのように機能するのか?

基礎となる複雑なコードを理解する必要はありません。このネットワークが **接続層 ** を通じて 3 つのコア機能を提供し、エージェントが人間のように交流できるようにすることだけを知っておいてください。

```
┌─────────────────────────────────────────────────────────────┐
│                        供给侧 (Supply Side)                   │
│  酒店智能体 | 餐饮智能体 | 教育/娱乐智能体 | ViNote ...       │
└─────────────────────────────────────────────────────────────┘
                            ↕
┌─────────────────────────────────────────────────────────────┐
│              连接层 (Connection Layer)                        │
│  1. 发现 (Discovery)  2. 描述 (Description)  3. 身份 (Identity) │
└─────────────────────────────────────────────────────────────┘
                            ↕
┌─────────────────────────────────────────────────────────────┐
│                       需求侧 (Demand Side)                    │
│  个人助手 | 垂直智能体 | AI应用 ...                           │
└─────────────────────────────────────────────────────────────┘
```

### 接続層用の 3 つの魔法の武器:

1.  **エージェント検出 (検出) **:
ブラウザが任意の Web サイトを見つけるのと同じように、エージェントは標準メカニズムを通じてお互いを見つけることができます。
2.  **エージェントの説明 (説明) **:
「サービス説明書」のようなもの。標準ドキュメントを通じて、インテリジェント エージェントは、手動でドッキングすることなく、相手が実行できることとその呼び出し方法を自動的に理解できます。
3.  **エージェント ID (アイデンティティ) **:
これが最も重要な部分です。当社は **DID (分散型 ID) ** を使用します。これは、各エージェントに ** グローバル「デジタル ID カード」** を発行するのと同等です。
    *   各プラットフォームに登録する必要はありません。
    *    1 つのアイデンティティがインターネット上を移動します。
    *   **あなたのアイデンティティは完全にあなたの管理下にあります**。

## 実際のケース: 3 時間、「ツール」から「ネットワーク ノード」に変換

理論では多くのことが語られますが、実際のケースを見てみましょう: **ViNote**。

**ViNote** 動画をメモやマインドマップに変換できるAIビデオメモツールです。
開発者はもともと、便利な SaaS ツールを作りたかっただけです。

しかし、**ANP SDK** に接続した後、素晴らしいことが起こりました。
**わずか 3 時間** で、ViNote は独立したアプリケーションから**エージェント ネットワーク ノード** に変わりました。

*   **以前 **: ユーザーは ViNote Web サイトを開く必要があります。
*   **現在 **:
    *   特定の**教育エージェント**は、ViNoteを直接呼び出してオンライン授業ビデオを復習教材に変換し、学生に送信できます。
    *   特定の**コンテンツ作成エージェント**は、ViNoteを呼び出してビデオ素材からゴールデンセンテンスを抽出し、記事を書くことができます。

** ViNote の開発者は、自分たちのツールがネットワーク全体上の他のエージェントからのトラフィックや通話を瞬時に受信できるとは想像もしていませんでした。 **
これはネットワークの価値です。**接続は付加価値を追加します。**

## 未来は、私たちが築き上げたものは何ですか?

オープンソースのスマートネットワークは、ただ始まりに始まります。さらに、エキサイティングなモジュールがライン上にあります。

### 1. スマート決済
AP2プロトコルに基づくスマートは「ボルダバッグ」を持っています。
サービスは、API で呼び出されることで直接利益を出すことができます。これはインテリジェントな体の商用閉鎖の鍵です。

スマートボディネットワークの開発者にお金を使うと、スマートな人のための支払いは必須インフラです。

### 2. スマートインスティテュートのインスタントメッセージング
「コールインターフェイス」だけでなく、人間のような「マイクロレター」もスマートに。
コミュニティベースのコラボレーションと情報共有が可能なクロスプラットフォームのインテリジェンス。

### 3. 多面的なゲートウェイ:すべてを接続して下さい
ANPだけでなくゲートウェイの互換性もサポートします。
*   **MCP(モデルコンテキストプロトコル)**プロトコルを立ち上げたAnthropic。
*   **A2A(エージェント・ツー・エージェント)**: Google は合意を提唱しました。
*   **アクセシビリティ**OpenAI/Stripeのビジネス契約。

**MCP Agent を開発している場合は、オープンなスマートボディネットワークに1つのキーでアクセスできます。**
