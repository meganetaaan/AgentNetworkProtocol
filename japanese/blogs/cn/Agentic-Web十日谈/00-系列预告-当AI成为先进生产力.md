# 「Agentic Web Decameron」シリーズトレーラー

## AI が高度な生産性を実現するとき、なぜインターネットを再発明しなければならないのでしょうか?

2025 年末、目立たない事件がインターネット業界で白熱した議論を引き起こしました。ByteDance の Doubao モバイル アシスタントは、複数のアプリケーションにわたってタスクを完了できるため、WeChat などのプラットフォームによって制限され、さらには禁止されました。

これもまたプラットフォームの競合のように見えるかもしれませんが、私たちはそれをはるかに超えたものだと考えています。

**先進的な生産力が古いインターネット生産関係と正面から衝突するのはこれが初めてである。 **

---

## 無視されてきた根本的な問題

過去 30 年間、私たちはインターネットがオープンからクローズドに移行するのを目の当たりにしてきました。

- ワールド ワイド ウェブを発明したティム バーナーズ リーの当初の意図は、誰もが自由に情報に接続できるようにする「接続は力である」ということでした。
- HTTP プロトコルが成功したのは、シンプル、オープン、パーミッションレスであったためであり、Web 1.0 の繁栄に貢献しました。
- しかし今日、スーパープラットフォームがすべてを支配し、データアイランドがいたるところに存在し、オープン性は過去のものになりました。

**なぜ「つながる」ために生まれたネットワークは、やがて閉ざされてしまうのか？ **

多くの人はこれをビジネスの貪欲や道徳的退廃のせいだと考えていますが、この説明は単純すぎます。私たちは、閉鎖は陰謀ではなく、現在の技術的条件下でのインターネットにとって最適な解決策であると信じています。

**AI の出現により、この前提が根本的に変わりつつあります。 ** 最大の変化の 1 つは、インターネットの主体が人間とソフトウェアからインテリジェント エージェントに変わりつつあることです。

これにより、インターネットは新たな段階、**再開へと押し上げられます。 **

これがこれからお話しするトピック、エージェントティック Web、つまりインテリジェントな Web です。私の考えでは、これが本当の次世代 Web、つまり Web 3.0、オープン性を中核としたインターネットです。

## 「Agentic Web」で連載記事を始める理由

今年はコミュニティ開設のためにANPに取り組んでいたこともあり、多くの業界の方々とコミュニケーションをとることができました。コミュニケーションの過程で、Agentic Web のフレームワークが徐々に形成され、徐々に改善されていきました。この時点で、自分の考えを体系的に整理する必要があります。公的なアカウントを書くことは、私にとって常に深く考える方法でした。

AIを使っているかもしれませんが、枠組みやアイデアは間違いなく私のオリジナルです。ただし、AI の助けを借りても、毎日の更新が保証されるわけではありません。

新年最初の旗、粘って終わらせたいと思います。
