# Agentic Web Decameron · 3 日目: Agentic Web とは何ですか?エージェントがインターネットの最初の住民になるとき

> 最近忙しくて、前回の記事から今回の記事までかなり期間が空いてしまいました。しかし、私はそれを終わらせることに固執します。

> **核心的な質問**: インターネットの主なユーザーがもはや「人」ではなく「エージェント」になったら、このネットワークはどのようになるでしょうか?

過去 2 日間で、私たちは Web 閉鎖の歴史を検討し、新しい実行主体としてのエージェントがコンテキストと実行機能を取得するためにオープンなインターネット環境を必要としていると推測しました。

多くの人は、「あなたが話している Agentic Web は、現在のインターネットと API のことではありませんか?」と尋ねるでしょう。

答えはノーです。

**Agentic Web は、既存のインターネット上のパッチではありません。 ** モバイル インターネットが単なる「PC インターネット + 携帯電話」ではないのと同様に、位置情報サービス、常時接続、タッチ インタラクションなどの新しいパラダイムをもたらします。

Agentic Web には 3 つの変更も加えられています。これらの変化について議論する前に、これを明確に定義しましょう。

---

## 1.エージェント Web の定義

Agentic Web を一文で定義すると、次のようになります。

> **Agentic Web は、エージェントを主体とし、標準プロトコルを核とし、オープンコラボレーションを基本形態とする新世代のインターネットです。 **

ここには 3 つのキーワードがあります。

1.  **インターネット主題 (インターネット主題) **: 「人間」から「インテリジェント」へ。
2.  **プロトコル中心**: 「UI」から「プロトコル」に変更されました。
3.  **オープンコラボレーション（オープンコラボレーション）**：「データアイランド」から「オープン接続」へ。

これは少し抽象的に聞こえますか? 3 つの具体的な変革でそれを分析してみましょう。

---

##  2. 変化1：「Webページを見る人」から「インテリジェントなサービス」へ

**現在のインターネットは、注目を集める競争のようなものです。 **

ニュース Web サイト、ソーシャル メディア、電子商取引プラットフォームなど、それらはすべて人間の注目を集めるために競争するように設計されています。インターフェイスはますます美しくなり、インタラクションはますます中毒性が増し、アルゴリズムはユーザーの好みを理解する能力がますます向上しています。

このレベルでは、エージェントは主に、Web ページを要約して応答を生成するのに役立つ補助ツールです。 ** 人が依然としてネットワークの主体です。 **

**Agentic Web は「ミッションの完了」をより重視します。 **

Agentic Web では、ネットワークにアクセスする主体はもはや人間ではなく、人間の意図を代表するエージェントです。

-   **人間によるアクセス**: ページを閲覧 → 情報を理解 → ボタンをクリック → タスクを完了します (チケットの購入など)。
-   **エージェントは**にアクセスします: インテントの受信 → サービスの検出 → パラメータのネゴシエート → トランザクションの実行 (チケット予約契約を直接呼び出すなど)。

エージェントが「最初の市民」になると、インターネットの評価基準も変わります。
「現場滞在時間」から「タスク完了率」へ。
「毎日のアクティブ ユーザー」（DAU）から「毎日のサービス コール」（サービス コール）へ。

**エージェントはもはや単なるツールではなく、事務を直接処理する役割です。 **

> **【イラストコンセプトのヒント】**
>
> **画面の説明**:
>  左側は「ヒューマン ウェブ」です。人は、ポップアップ、広告、明るいボタンでいっぱいの無数の点滅する画面 (Web ページ、アプリ) に直面し、人々の注意を引こうとしています。
>  右側は「Agentic Web」です。明確なパイプラインとインターフェイスに面したエージェントで、「支払い」、「物流」、「カレンダー」などの機能モジュールに直接接続されています。広告や気を散らすものはなく、ただ秩序あるデータの流れだけです。
> **コアメタファー**: 左側は迷路、右側は直接通路です。

## 3.変革 2: UI 主導からプロトコル主導へ

ユーザーが「人」から「インテリジェントエージェント」に変わった今、接続方法も変わらなければなりません。

現在、エージェントに食べ物の注文を手伝ってもらいたい場合、既存のソリューション (コンピュータの使用やブラウザの使用など) は依然として人間の操作をシミュレートしています。
1.  ブラウザを開く
2.  URLを入力してください
3.  ページの読み込みを待機中（広告を含む）
4.  どれが「予約」ボタンであるかを確認してください
5.  マウスクリックをシミュレートします

**これは非効率的で脆弱な移行ソリューションです。 ** Web ページの改訂、ボタンの位置変更、ポップアップ広告、UI の軽微な変更により、タスクが失敗する可能性があります。

** Agentic Web では、プロトコルが UI に代わってコアとなります。 **

サービス プロバイダーは、HTML Web ページを提供するだけでなく、標準の **Agent description Protocol** を提供します。
-    エージェントに「これは予約という赤いボタンです」と伝える必要はありません。
-   直接合意して、それを伝えます。`Function: book_table(time, pax, requirements)`。

UI は人間指向であり、視覚的なフィードバックと感情的なガイダンスを必要とします。
このプロトコルはマシン指向であり、構造化データと決定論的ロジックを必要とします。

**将来のインターネットは 2 つの層に分かれます: **
1.  **Surface (Human Layer) **: 人間のエンターテイメント、ソーシャル インタラクション、エクスペリエンスのための絶妙な UI を保持しています。
2.  **内層 (エージェント層) **: エージェントがデータを交換してタスクを実行するための、標準プロトコルに基づく機能ネットワーク。

**Agentic Web は形成中の「内層」です。 **

> 前半: エージェントは Web ページの解析を通じてサービスを理解します。この手順は面倒で、間違いが発生しやすくなります。

##  IV.変化 3: プラットフォームの閉鎖からオープンなコラボレーションへ

これが最も難しい移行です。

現在のインターネットは「プラットフォームベース」です。スーパー アプリは、すべてのサービスを独自の壁の中に囲い込みたいと考えています。「タクシーに乗りますか?」私のものを使ってください。テイクアウトしたいですか？私のものを使ってください。映画を見たいですか？それはまだ私のアプリにあります。

このモデルは人間にとっては肥大化していますが、それでも許容できます。インテリジェントエージェントの場合、それは明らかに制限されています。

**知能エージェントは本質的に「結合」する能力を必要とします。 **

シナリオを想像してください:**「日本への旅行の計画を手伝ってください。」**

閉じたネットワークでは、どのアプリもこのタスクを独立して完了することはできません。
-   旅行アプリはチケットを予約できますが、（カレンダーアプリ内の）あなたのスケジュールは知りません。
-    カレンダー アプリは時刻を知っていますが、(銀行アプリで) 支払うことができません。
-   銀行アプリは支払うことができますが、（ソーシャルアプリでの）戦略の好みを理解できません。

Agentic Web の接続フォームは**分散型コラボレーション**:

ユーザーの「パーソナル アシスタント エージェント」は、それ自体がすべての機能を備えている必要はなく、他の専門エージェントを動的に検出して接続できます。
1.   は、**「旅行計画エージェント」** を呼び出し、ルートを生成します。
2.  「旅行計画エージェント」は、**「カレンダーエージェント」**に空き時間の確認をリクエストします。
3.   が確認されたら、**「航空券予約エージェント」** と**「ホテル予約エージェント」** をスケジュールして注文します。
4.  最後に**「支払いエージェント」**に電話して決済を完了します。

これらのエージェントは、異なる会社や個人の開発者に属している場合もありますが、共通の **エージェント通信プロトコル** を通じて連携します。

** これはもはや「孤立した島」ではなく、組み立てることができる能力のネットワークです。 **

## 5.なぜこれが単なるテクノロジーのアップグレードではないのでしょうか?

上記 3 つの変更を理解すると、Agentic Web が「接続目標の復活」であると言える理由が理解できるでしょう。

World Wide Web を作成したときのティム バーナーズ リーの当初の目的は「接続する」ことでした。
-   Web 1.0 ドキュメントがリンクされています。
-   Web 2.0 は人々を結びつけます。
-   **Agentic Web はサービスとアクションを接続します。 **

エージェントがプラットフォームの壁を越えてネットワーク内をスムーズに流れることができるとき。
サービス機能が電気に似ている場合、標準ソケット (プロトコル) を介したプラグ アンド プレイが可能です。
すべての小規模な開発者は、プロトコルを通じてグローバル インテリジェンスによって発見され、呼び出されることができます。

私たちが目にするのは効率の向上だけではありません。

## 結論: 理想はいっぱい、現実は細い

「音がいいけど、巨人はそう言ってる?」

エイジニック・ウェブの考え方に多くの人の反応が起きています。

確かに、既存のインターネットの巨人は閉鎖したエコロジーに依存して大きな利益を産みてきました。彼らは彼らのドアを開けて壁を壊すことを可能にし、それは虎と陰謀に有刺されます。

**紛争が始まりました。**

2024年後半と2025年初頭に、古い生産でインテリジェントな生産性の第一弾の暴力的衝突を目撃しました。ビーンバッグ電話アシスタントは殺されました。

単なる商用紛争ではありません。それは信号です。**新規の実装者が、古い生産関係を通る旅行しようとすると、それは必然的に炎から出ます。**
