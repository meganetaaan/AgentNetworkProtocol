## 第二日目

### **なぜ AI にはオープンなインターネットが必要なのでしょうか? Agentic Web の第一原則**

(対応: なぜ AI にはオープンなインターネットが必要なのか)

**Core judgment (one sentence) **

> The Internet is closed because it serves people; AI はアクションを必要とするため、オープンである必要があります。

**構造概要**

* The essential capabilities of AI/Agent: understanding → decision → execution
* クローズドプラットフォームがコンテキスト、機能、実行パスをどのように遮断するか
* オープン性は価値観ではなく、第一原則です
* Agentic Web’s three “non-negotiable conditions”:

  * コンテキストは流動的です
  * 能力発見可能
  * アクションは組み合わせることができます

## 3日目

### ** Agentic Web とは何ですか?エージェントがインターネットの最初の住民になるとき**

(Corresponding to: What is Agentic Web and what are its characteristics)

**中心的な質問**

> What will the Internet become if instead of “people clicking on web pages”, it becomes “intelligent agents doing things”?

**構造概要**

* Agentic Web の一文の定義: エージェントを本体、プロトコルをコア、オープン コラボレーションを基本形式とする新世代のインターネット
* 3 つの主な変更点 (写真の 3 つの点に対応):

  * 「人々がウェブページにアクセスする」から「インテリジェントエージェントが人々に代わって行動し、協力し、意思決定を行う」へ
  * UIドライバーからプロトコルドライバーへ（標準プロトコル、インターフェース、機能呼び出しがコアとなる）
  * プラットフォームの閉鎖からオープンコラボレーションへ（クロスプラットフォームの発見、接続、コラボレーション）

## 4日目

### **最初の正面衝突：Doubaoモバイルアシスタントと古いインターネットの生産関係**

（該当：Beanbaoブロック事件）

**コア判定（一文）**

> Beanbaoは製品イベントではありませんが、先進的な生産性が古いインターネット生産関係と正面から衝突する初めてのイベントです。

**構造概要**

* Doubao モバイル アシスタントが表す生産性: Doubao モバイル アシスタントはすべてを操作し、すべてを接続できるからです。利用方法はコンピュータだが、パーソナルアシスタントの形を人に見せる初めての製品だ。
* なぜ「クロスアプリケーション操作」が集団的封鎖を引き起こすのか: 根本的な理由はビジネスモデルの矛盾にあります。他人のために結婚式の衣装を喜んで作るアプリはありません。
* プラットフォーム禁止の構造的理由: プラットフォームは十分強力であり、サービス機能を短期的に「分割」するインセンティブはありません。これはサービスの生命線を遮断することに等しいです。
* これは新しい生産性と生産関係の最初の衝突であり、将来的にはさらに衝突するでしょう。

Qianwen は Alibaba の社内エコシステムをオープンにしましたが、本質的には依然としてクローズドな製品です。

## 6日目

### **エージェント プロトコル: AI 時代の HTTP が形になりつつある**

（対応：インテリジェントエージェントプロトコル）

**コアジャッジメント**

> UIは人間向けに設計されており、プロトコルはAI向けに設計されています。

**構造概要**

* ブラウザを使用する理由 / UI オートメーションは暫定的なソリューションにすぎません
* 階層化プロトコルスタックの必要性
* プロトコルによって解決される最小限の問題セット
* 主流プロトコルの比較:

  * MCP: モデルセンター
  * A2A: フェデレーション ネットワーク
  * ACP: クイックランディング
  * ANP: 分散型コラボレーション

## ライティングガイド

### コンテンツ構造の提案
各記事は次のような構成を採用しています。
1. **はじめに**(10%): トピックを紹介し、興味を刺激します
2. **核となるアイデア**(5%): 1 文の要約 + 3 ～ 5 つの重要なポイント
3. **メインコンテンツ**(75%): テーマごとに展開され、事例が散りばめられています
4. **概要と展望**(10%): テーマに答えて次の記事につなげます

### スタイル要件
- **深さと幅のバランス**: テクノロジー、ビジネス、トレンドの 3 つの側面を考慮する
- **中立的かつ客観的**: ANP はケースの 1 つであり、過度に宣伝されるべきではありません
- **豊富な事例 **: 例として特定の企業、製品、契約を引用
- **可読性 **: 過度に専門的な表現を避け、例えや図を使用します。
- **原因思考 **: 自由形式の質問をして、読者に深く考えるよう促します。
