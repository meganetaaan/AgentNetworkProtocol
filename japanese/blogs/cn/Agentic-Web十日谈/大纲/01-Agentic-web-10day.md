## 1日目 **World Wide Webから巨大プラットフォームへ：Webが閉じていく歴史的な必然性**

**中心となる問い**

> 「つながり」を可能にするために生まれたネットワークが、プラットフォーム化し、閉じていくことを避けられないのは、なぜか。

**構成案**
- Webの命名の由来と、Tim Berners-Leeの当初の意図（接続は力である）。
- Web 1.0：HTTPの成功の四つの理由（単純、開放、許可不要、既存の基盤に基づく）。
- Web 2.0：開放から、プラットフォームによる独占への転換（Facebook、Google、Amazonの台頭）。
- 次世代Webの探究1：セマンティックWebが失敗した深い理由。手作業による注釈のコストが高すぎたこと、商業的な動機の不足、技術の仕組みの複雑さ。
- 次世代Webの探究2：Web3の問題と教訓。ブロックチェーンへの過度の依存、性能の制約、利用体験の隔たり。
* 一つの判断：閉鎖は陰謀ではなく、従来の生産力の条件下での最適解だった。規模の効果によって、一つのソフトウェアを開発し、すべての人に使ってもらい、利用者が多いほど効率が上がる。そのため、従来のWebには、独占的なプラットフォームを形成する、根本的な推進力がある。

結び：Webの進化は、誤りの連続ではなく、各世代の生産力の条件下で、最適解を選んだ結果である。

詳細な構成案：

### 1️⃣ World Wide Webの当初の意図：接続は力である

* Tim Berners-LeeがWebを発明した目的：
  * 情報を自由につなげるようにする。
  * 知識の伝達の障壁を下げる。
* 「接続は力である」の本来の意味：
  * **つながることができるものは、見つけてもらえる。**
* 最初のWebは、**プラットフォームではなく、基盤だった。**

👉 土台となること：**開放は、標語ではなく、出発点である。**

---

### 2️⃣ Web 1.0：HTTPはなぜ成功したのか

* HTTPの成功の四つの条件：
  1. 単純（実装のコストが非常に低い）。
  2. 開放（許可を必要としない）。
  3. 分散（単一の支配点がない）。
  4. 既存の基盤を再利用する。
* 本質的な判断：
  * Web 1.0が解放したのは、**情報を生産し、配布する能力**である。
  * 主な「解釈者」と「実行者」は、人だった。

👉 生産力の主体は、依然として**人**である。

---

### 3️⃣ Web 2.0：プラットフォーム化は裏切りではなく、効率の選択

* 利用者の規模と、やり取りの複雑さが増えるにつれて：
  * 情報が過剰になる。
  * 関係を管理するコストが急増する。
* プラットフォームの登場は、三つの問題を解決した。
  * コンテンツの選別（検索／推薦）。
  * 関係の整理（ソーシャルグラフ）。
  * 取引の仲介（電子商取引、広告）。

👉 重要な判断：
**プラットフォーム化は、人の注意力と操作能力に合わせた最適化の結果である。**

---

### 4️⃣ 閉鎖と独占の内側にある推進力

* ソフトウェアの限界費用は、ゼロに近づく。
* 規模が大きいほど：
  * データが増える。
  * アルゴリズムがよくなる。
  * 体験がよくなる。
* 正のフィードバックの循環ができる。

  > 利用者が増える → 効率が上がる → 囲い込みが強まる → プラットフォームが大きくなる

👉 **閉鎖は道徳の問題ではなく、生産力の条件が決めた構造的な結果である。**

---

### 5️⃣ セマンティックWebもWeb3も、なぜ閉鎖を打破できなかったのか

**セマンティックWebの失敗：**

* 手作業による注釈のコストが高すぎる。
* 直接的な商業上の見返りがない。
* 技術の複雑さが、当時の生産力の水準を超えていた。

**Web3の限界：**

* 「信頼の問題」を「ブロックチェーンに載せる問題」に単純化した。
* 利用体験と効率を軽視した。
* 「誰が行動するのか」という問題を解決しなかった。

👉 共通の問題：
**どちらも、「制度や技術の理想」で、当時の生産力の現実に対抗しようとした。**

---

### 6️⃣ 一つの重要な結論（後の議論の前提を定める）

> **従来のインターネットが閉じていったのは、当初の意図に背いたからではない。
> 人が主な生産力である時代には、それがすでに最適解だったからである。**

* 一度開発したソフトウェアで、すべての人にサービスを提供する。
* 利用者が多いほど、効率が上がる。
* 独占は偶然ではなく、内側から生じた結果である。

---

## この記事の「歴史的な位置付け」（念頭に置くこと）

この記事では、「プラットフォームを批判する」のではなく、**一つのことを証明する。**

> **生産力が変化しなければ、インターネットが自動的に開放へ戻ることはない。**

これは、ちょうど次の記事、
👉 **「なぜAIには、開かれたインターネットが必要なのか」**
に対する、**反論できない歴史的な前提**となる。
