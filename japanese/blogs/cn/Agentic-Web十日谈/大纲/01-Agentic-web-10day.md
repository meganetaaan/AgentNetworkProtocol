## 1日目**World Wide Webからスーパープラットフォームへ: Web閉鎖の歴史的必然性**


**中心的な質問**

> なぜ「つながる」ために作られたネットワークは必然的にプラットフォーム化、クローズド化してしまうのでしょうか？

**構造概要**
- Webのネーミングの由来とティム・バーナーズ・リーの初心（つながりは力）
- Web 1.0: HTTP プロトコルの成功の 4 つの理由 (シンプル、オープン、パーミッションレス、既存のインフラストラクチャに基づく)
- Web 2.0: オープンからプラットフォーム独占への変化 (Facebook、Google、Amazon の台頭)
- 次世代 Web の探求 1: セマンティック Web の失敗の根本的な理由: 手動によるアノテーションのコストが高すぎる、ビジネス推進力の欠如、技術スタックが複雑すぎる
- 次世代 Web の探求 2 Web3 の問題点と教訓: ブロックチェーンへの過度の依存、パフォーマンスのボトルネック、ユーザー エクスペリエンスのギャップ
* 判決: 閉鎖は陰謀ではなく、古い生産性条件下での最適な解決策です。スケール効果、ソフトウェアを開発し、すべての人が利用できるようにします。使用する人が増えれば増えるほど効率が上がります。したがって、伝統的なウェブは独占プラットフォームを形成するための独自の原動力を持っています。

結論: Web の進化は間違いの連続ではなく、各世代の生産性条件下での最適なソリューションの選択です。

詳細な概要:

### 1️⃣ World Wide Web の本来の目的: 接続は力です

* ティム・バーナーズ・リーがウェブを発明した当初の意図:

  * 情報リンクはご自由にどうぞ
  * 知識普及の敷居を下げる
* 「つながりは力」の本来の意味：

  * **接続できる人は誰でも見ることができます**
* まずはWebです。**インフラ、プラットフォームではなく**

👉 基礎を築く:**オープニングはスローガンではなく出発点です**

---

### 2️⃣ Web 1.0: HTTP はなぜ成功するのでしょうか?

* HTTP が成功するための 4 つの重要な条件:

  1. シンプル (導入コストが非常に低い)
  2. 開く（許可は必要ありません）
  3. 分散化 (単一制御点なし)
  4. 既存のインフラストラクチャを再利用
* 本質的な判断:

  * Web 1.0 は、**情報の作成および配布機能**を解放します
  * 人々が主な「通訳」と「実行者」

👉 生産性の主体は依然として**人**

---

### 3️⃣ Web 2.0: プラットフォーム化は裏切りではなく、効率性の選択です

*  ユーザーの規模とインタラクションの複雑さが増すにつれて、次のようになります。

  * 情報過多
  * 人間関係管理コストが急増
*  プラットフォームの登場により、次の 3 つの問題が解決されました。

  * コンテンツフィルタリング（検索/おすすめ）
  * Relationship Organization (Social Graph)
  * トランザクションマッチング（電子商取引、広告）

👉 重要な判断:
**プラットフォーム化は人間の注意力と操作能力を最適化した結果です**

---

### 4️⃣ 閉鎖と独占の内なる原動力

*  ソフトウェアの限界費用がゼロに近づく
* スケールが大きいほど:

  * データが多いほど
  * アルゴリズムが優れているほど
  * エクスペリエンスが向上するほど
*  正帰還フライホイールを形成します。

  > ユーザーの増加 → 効率の向上 → ロックインの強化 → プラットフォームの大型化

👉 ** 閉店は道徳的な問題ではなく、生産性の条件によって決定される構造的な結果です **

---

### 5️⃣ Why haven’t Semantic Web and Web3 broken the barrier?

**セマンティック Web の失敗: **

* 手動ラベル付けコストが高すぎます
* 直接的な商業的利益の欠如
* 技術的な複雑さが当時の生産性レベルを超えていた

**Web3 の制限: **

*  「信頼の問題」を「オンチェーンの問題」に簡略化する
* Ignore user experience and efficiency
* 「誰が行動するのか？」という疑問が解決しない。

👉 よくある質問:
**They all tried to use “institutional or technical ideals” to fight against the reality of productivity at the time**

---

### 6️⃣ 重要な結論 (次の本文の法律)

> **The traditional Internet is becoming closed, not because it has deviated from its original intention.
>  でも、「人間が主な生産力」の時代ですから、それはすでに最適解なんです。 **

*  ソフトウェアを一度開発すれば、すべての人にサービスを提供できる
*  ユーザーが多いほど、効率が高くなります。
* 独占は偶然ではなく内生的な結果である
