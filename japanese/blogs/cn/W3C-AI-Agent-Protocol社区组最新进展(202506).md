# W3C AI エージェント プロトコル コミュニティ グループの最新の進捗状況 (202506)

標準化されたエージェント通信プロトコルを確立するために、ANP (エージェント ネットワーク プロトコル) オープン ソース コミュニティが主導する AI エージェント プロトコル コミュニティ グループが W3C に設立されました。この記事では、このコミュニティ グループの最新の進捗状況について詳しく説明します。

コミュニティグループは、2025年6月18日に第1回会議を開催しました。会議では主にコミュニティグループの目標、業務範囲、会議の仕組み、フォローアップ計画などについて議論されました。

会議議事録のリンク: https://github.com/w3c-cg/ai-agent-protocol/blob/main/meetings/2025-06-18.md

## コミュニティグループの背景と構成

W3C AI エージェント プロトコル コミュニティ グループは、エージェント通信プロトコルの標準化プロセスを促進するために、W3C の ANP オープンソース コミュニティによって開始および主導されました。 ANP コミュニティの創設者である Chang Gaowei は、コミュニティ グループの共同会長を務めており、関連作業の調整と推進を担当しています。

現在、次のような多くの国内外の有名企業や学術機関がこのコミュニティ グループに参加しています。

- マイクロソフト
- アントグループ
- チャイナモバイル

**学術機関: **

## コミュニティグループの使命と業務範囲

### ミッションステートメント

AI Agent Protocol コミュニティ グループの使命は、エージェントがインターネット上で効率的に検出、接続、共同作業できるようにする、オープンで相互運用可能なプロトコルを開発することです。エージェントがインターネット ベースのアクティビティに参加することが増えるにつれ、安全で信頼性が高く、スケーラブルな対話をサポートする標準化されたメカニズムの必要性が高まっています。この組織は、新興の「Agentic Web」の技術基盤を確立することを目的としています。

### 作業範囲

このコミュニティ グループは、次の主要な領域を調査し、定義します。

**1.エージェント間通信プロトコル **
- エージェントがお互いを発見できるメカニズムを確立する
- 意図と機能の情報を交換する
-  役割分担を交渉する
- オープンな Web 環境でコラボレーション関係を動的に確立または解消する

**2.エージェント ID モデル **
- オープンスタンダードに基づくAIエージェントアイデンティティフレームワーク
- クロスドメインエージェント間の安全で相互運用可能な認証をサポート

**3.標準化されたメタデータ形式 **
- エージェントの機能、インターフェース、目標、状態の構造化された説明
- Web ネイティブ形式に基づいており、エージェントの動作の自動推論、組み合わせ、オーケストレーションをサポートします。

**4.セキュリティとプライバシーのメカニズム**
- エージェントクロスドメイン通信セキュリティモデル
- 検証可能な資格情報に基づく認証、認可、信頼メカニズム
- エンドツーエンドの暗号化により、エージェントとの対話の整合性と機密性を保護

**5.プロトコルの相互運用性 **
- 既存の Web プロトコルと標準を使用して、エージェントベースのシステムを統合および連携できるようにする

このコミュニティ グループは、関連する技術仕様をリリースし、AI プラットフォーム開発者、プロトコル設計者、ブラウザ メーカー、Web アプリケーション開発者、学術研究者、および信頼できる協調的なインテリジェント エージェント Web エコシステムを共同で構築するためのオープン スタンダードの推進に関心のあるその他の関係者の参加を歓迎します。

## 主な出力結果

コミュニティ グループは 2 つの重要な技術文書を作成しました。

### 1. エージェント ネットワーク プロトコル ホワイト ペーパー ドラフト
**文書リンク:** https://w3c-cg.github.io/ai-agent-protocol/

このホワイト ペーパーでは、エージェント ネットワーク プロトコルの技術的背景、開発傾向、標準化のニーズについて詳しく説明します。この文書では、エージェント テクノロジーの現在の開発状況、直面している課題、および今後の開発の方向性について説明します。

### 2. インテリジェント エージェント プロトコル技術仕様フレームワークの草案
**文書リンク:** https://w3c-cg.github.io/ai-agent-protocol/protocol.html

この技術フレームワークは、次のようなエージェント プロトコルの特定の実装の主要モジュールを詳細に定義します。
- エージェント ID 認証メカニズム
- エージェントの検出および説明プロトコル
- エージェント間通信規格
- セキュリティとプライバシー保護メカニズム
- プロトコル相互運用性設計
