#  Agentic Web と Agentic Web の違いは何ですか?

インテリジェント エージェントは基本的に、**AI 業界** のコンセンサスとなっています。意見の相違がある場合、それは実装時期についての意見の相違である可能性が高くなります。現在、業界は主にエージェント自体を構築する方法に関心を持っています。エージェントがどのように連携するか、およびエージェント ネットワークの特性についてはあまり研究されていません。

この記事では、インターネットの進化の本質である ** 新しいテクノロジーをリリースする能力 ** に基づいて、Agentic Web と既存のインターネットの違いを探っていきます。

私たちは、ソフトウェア自体への大幅な変更に加えて、エージェントが **重大な変更** をインターネットにもたらすと考えています。

現在の世界のインターネット市場の規模から判断すると、インテリジェント インターネットの何が違うのかというと、少なくとも数千億ドルの価値がある問題です。

この記事の重要なポイント:

- インターネットの進化の方向性に関する最も重要な質問は、それがどのように機能するかです。**新たな技術のリリースを最大限に活用する能力**次世代のインターネットは、AI技術の発展に大きな影響を与えるでしょう。
-  AI の力を解き放つには、AI が完全なコンテキスト情報を取得できること、インターネット上のすべてのツールを呼び出すことができること、得意な方法でインターネットと対話できること、インターネット上の他の AI と効率的に連携できることが必要です。
- そのためには、**相互接続**、**ネイティブインターフェース**、**効率的なコラボレーション**の3つの問題を解決する必要があります。
- API または通信プロトコルは、AI がインターネットと対話するための最良の方法です。私たちは、AI が人間を模倣することを可能にするコンピューター使用テクノロジーについて楽観的ではありません。 AI携帯電話は、端末上のさまざまなAPPを接続するためのソリューションを提供します。 Anthropic の MCP は、私たちのビジョンに最も適したテクノロジーです。
- **パーソナルアシスタント**は、次世代インターネットへの新たな入り口となります。インテリジェントなエージェントはインターネットの隅々まで侵入します。インテリジェント エージェントは相互接続できます。自己組織化し、自己交渉して、効率的なコラボレーション ネットワークを構築できます。
- 私たちは、エージェント通信用のオープンソース プロトコルであるエージェント ネットワーク プロトコル (ANP) を開発しており、エージェントのインターネット時代の HTTP になることを目標としています。

##  インターネットの進化の方向性を決定する本質的な問題は何ですか?

インターネットの運転方法や、ボトムアップの運転力が最も根本的な問題は、どのように機能するかを信じています。**新たな技術を発表する能力**。

質問を分析してみましょう。PC インターネット時代には Web ベースの製品が使用されるのに、モバイル インターネット時代には APP ベースの製品が使用されるのはなぜですか?

PCインターネット時代の新技術は主にネットワーク通信技術（TCP/IP、DNS、HTTP）、Web技術（HTML、CSS、JavaScript）、データベース技術、情報検索技術などでした。ブラウザやWeb技術をメディアとした製品形態は、オープンなインターネットへのアクセス機能を解放し、統一された入り口から広く情報を入手できるようにします。

当時の技術的条件 (限られた帯域幅とハードウェア パフォーマンス) および Web テクノロジのクロスプラットフォーム特性と相まって、Web は PC インターネットに最も適した製品形式であると判断されました。

モバイル インターネットの時代には、モバイル デバイスとハードウェア (加速度計、ジャイロスコープ、GPS、タッチ スクリーン、カメラ、チップ)、モバイル ネットワーク (3G、4G、5G)、モバイル オペレーティング システム (iOS、Android) などの新たなテクノロジが登場します。

Web テクノロジーと比較して、APP はオペレーティング システムの API を通じてハードウェア機能を深く統合し、デバイスのパフォーマンスに応じて動作効率を最適化し、継続的にオンラインでリアルタイムに対話することができます。

まさにこれらの要因によって、APP を通じて新しい技術機能がリリースされ、APP のエクスペリエンスは Web のエクスペリエンスをはるかに超え、APP がモバイル インターネット時代の主流の製品形式となっています。

現在および今後 10 年間の新しいテクノロジーは、間違いなく、生成人工知能、大規模言語モデル、エージェントに代表される AI テクノロジーです。 AIの力をいかに解き放つかが、今後のインターネットの進化の方向性を決定する。

## 次世代インターネットはAIの力をどのように解き放つべきか

現在のインターネットインフラはかなり完成されていますが、AIの特性を踏まえると、AIの能力を最大限に発揮するにはまだ課題がいくつかあります。

### AI に**完全なコンテキスト情報** を取得させる方法、および AI に**すべてのツール機能** を呼び出させる方法

AI が完全なコンテキスト情報を取得した場合にのみ、正しい判断を下すことができます。すべてのツール機能を呼び出すことができて初めて、複雑なタスクを効率的に完了できます。

しかし、現在のインターネットは基本的に情報の島で構成されており、島間の情報の流れが困難です。

以前は、情報分離の偏心として行動していた人達が、視聴者やアプリ、検索エンジン、ソーシャルネットワークなどとつながることで、AIでより効率的に作業するようになりました。

AAI携帯電話、コンピュータ利用技術など、これらの問題を解決しようとする技術ソリューションが今ではあります。これにより、AIはグラフィックインターフェイス、ブラウザ、またはAPPターミナルを使用してインターネットに接続することができます。しかし、これは最も効率的な解決策ではないと思います。

### 人工知能がインターネットにアクセスする方法を最善の方法で取得する方法。

インターネットはインターネットの新サイトであり、AIがアクセスできるようになりました。

1. **コンピュータ利用技術**

多くのモデルメーカーが同様のプログラムを導入しています。

しかし、私は本当に技術に感謝していません。 そこで出てきたのは、元のインターネット製品は人間の使用のために設計されていたことであり、AIに再設計された前に、AIが学習し、人々を模倣するために確かに最速の方法だったということです。 それは最も効率的なパスではありませんでした。

2. **AI携帯電話プログラム**

例えば、りんごの侵入も国の多くの携帯電話メーカーによって促進されます。

この技術は、APPクライアントとのオープンインターフェイスを介してターミナルでインターネットデータと機能にアクセスすることによって特徴付けられます。

この技術は、AIが自然位置にあるコンピュータ使用よりもさらに高度化され、それは、グラフィックではなく、データを処理することです。しかし、このプログラムでは、端末でのAPの位置は非常に厄介であり、AID携帯電話は競争的で協力的です。AI電話からのトラフィックへのアクセス権を獲得し、AI電話による交換のためのあまりにも多くのデータを開くことを望んでいます。

3. **クラウデ MCP**

現在のシナリオでは、最も適切なオプションです。

わたしたちは、**人間とは異なるAIで、グラフィックインターフェイスよりも下部のデータを処理するのが良いです。**.AIは最善を尽くす方法で行うべき。**API または通信契約**)インターネットとの相互作用。

私たちが世界観に最も大きな違いを抱えるMCPは、
- MCP はモデルに基づいており、インターネット全体が彼のコンテキストとツールです。
- インテリジェントなコラボレーションのネットワークとして、集中的なインテリジェンスを持つ(エージェント・ネットワーク・プロトコル)。

### 人工知能をインターネット上で他のAIと効率的に動作させる方法

従来のネットワークノードは、ハードコーディングやマニュアルの手段によって接続されることが多いです。AI、ネットワーク接続、コラボレーションアプローチにより、より効率的な運用が可能です。

例えば、AI ノードは、それぞれが最初に使用して、各ユーザー間での能力とインターフェイスを通信し、標準または合意書とのコミュニケーションとコラボレーションを行うために、自然言語を生成および理解する能力を使用することができます。

より効率的で低コストのコラボレーションネットワークの構築に役立ちます。

最後に、AI のインターネット上の容量が完全にリリースされると、3つの問題が必要になります。

- 🌐 **接続性**: 知能が互いに通信できるようにするため、データの隔離の島を破り、AIがインターネット上のすべてのツールや全文情報にアクセスできるようにします。
- 🖥️ **ネイティブインターフェイス**人工知能はインターネットへの人的アクセスを制限する必要はありません。AIは、インターネットとやり取りする必要があります(APIまたは通信プロトコル)。
- 🤝 **効率的なコラボレーション**AI を使用して、インテリジェントなボディは、既存のインターネットよりもコスト効率の高いコラボレーションネットワークを構築するために、自分自身を整理し、自身で相談することができます。

## エージェントのWebはどのようなものですか?

スマートインターネットの定義はより大きな提案であり、学術的な厳格を与えることはできません。しかし、私たちは一般的な用語でそれを記述することができます。また、私たちが触れる部分を与え、私たちに触れる盲目の人です。

1. **スマートスは新しいです。**

PCインターネットはPCベースです。モバイルインターネットは、人体ベースのモバイル端末(MPエンド)インターネットであり、スマートインターネットは、デジタルワールドとやり取りする人々ではなく、人間ベースのインターネットを置き換えるスマートボディです。

エントリーポイントは、特別なインテリジェンスボディである:スーパーパーソナルアシスタントです。 これは、個人化されたUIを介してクライアント側で人間とインターネットアクセスしてやり取りし、人体を交換します。 バックエンドでは、APIまたはプロトコルを使用して他の知能機関と相互作用します。

<p align="center">
  <img src="../../../blogs/images/user-agent-internet.png" width="50%" alt="user-agent-internet"/>
</p>

2. **インターネットを透過させるスマート**

インターネットは、個人アシスタント以外の多くのスマートを持っていると思います。ホテル、レストラン、銀行、学校などのエンドユーザーと直接やり取りしないです。彼らは、個人アシスタントを介して間接的に人々を配信します。

3. **スマートは接続できます。**

個人的なアシスタントや、背後にあるスマートボディであっても、その会社が所属する各社とどのプラットフォームにいても、互いに接続することができます。

4. **よりフラットなネットワーク。**

スマートな人やエンティティティがインターネット上のノードの1つとして接続できる場合、集中型プラットフォーム(マイクロ・インテリジェンスやペドルなど)の役割は減少します。将来のインターネットはよりフラットになり、集中化されます。

5. **自己組織化された自己コンサルティングのための効率的なコラボレーションネットワーク**

効率的なコラボレーションネットワークは、自己組織化と相談を通じてインテリジェントな身体間で構築することができます。

## インフォメーション

最終的には、技術開発がインターネットの進化を牽引し、新しい技術を開発する能力を解明する方法を乗り越えるという点で、その方向性が変化する方向性を決めています。

スマートインターネットは出て行くつもりはないし、まだ確信していないが、私たちは確かにできるものの、インターネットの未来は間違いなくAI技術の発達の結果として、深く変化するということです。
