### Web の起源：もどかしさ

時がたつのは早いものです。実際、ほぼ 20 年前、情報の利用方法と協働の方法を作り直したいと思い、それを World Wide Web と名付けました。20 年後の今、TED の皆さんに、次の作り直しへの協力をお願いしたいのです。

1989 年、私は世界規模のハイパーテキストシステムを提案するメモを書きました。誰も具体的には動きませんでした。しかし 18 か月後、上司が、職場のコンピューターを使い、余暇の楽しみとして取り組んでよいと言いました。革新とはそういうふうに起きるものです。そこでコードを書く時間をもらえました。

HTML の形、ハイパーテキストのプロトコル HTTP、そして HTTP を整理する名前としての URL の概念を描き、コードを書いて公開しました。なぜか。基本的には、もどかしかったからです。私はとても刺激的な大研究所のソフトウェア技術者でした。世界各地から来る人々は、それぞれ異なるコミュニティ、データ形式、文書システムを持ち込んでいました。

この多様な情報から何かを作ろうとすると、別の機械に接続して、新しいプログラムの使い方を覚えなければなりませんでした。求める情報らしいデータがあっても、新しい形式で、互換性がありません。未活用の可能性がたくさんあることが、もどかしかったのです。実際、ディスクには文書がありました。それらすべてが、例えばインターネット上にある大きな仮想文書システムの一部だと考えられたら、ずっと楽になるはずでした。

一度そんな考えが浮かぶと、人がメモを読んでくれなくても心から離れません。実は上司は読んでいました。亡くなった後で見つかった彼の控えには、隅に鉛筆で「曖昧だが、わくわくする」と書かれていました。

### 草の根運動

Web がどんなものなのかを説明するのは本当に難しかった。今では当時の難しさを説明するのも難しいでしょう。TED が始まった頃には Web がなかったのです。ハイパーテキストのリンク付きページを見せ、リンクをクリックすると、*チン*、別のハイパーテキストページが現れます。

それだけでは驚かれません。CD-ROM にもハイパーテキストはありました。難しかったのは、そのリンク先が、想像できるほぼあらゆる文書になり得ると考えてもらうことです。その飛躍が難しかった。でも理解した人もいました。これは草の根運動だったからこそ面白かった。最もわくわくしたのは、技術やその用途よりも、コミュニティそのもの、皆が集まってメールを交わす精神でした。当時はそうだったのです。

今、また少し似た状況になっています。私は皆に、文書を Web に載せてほしいとお願いしました。皆さんは応えてくれました。ありがとう。本当に素晴らしいことです。最初のサイトを作ったときの想像をはるかに超えることが Web 上で起きて、驚かされたのです。

### データの重要性

今度は、データを Web に載せてほしいのです。まだ大きな可能性が眠っています。データをデータとして Web に載せていないために、今も大きなもどかしさがあります。「データ」とは何でしょう。文書とどう違うのでしょう。文書は読むもので、リンクを置けますが、基本的にはそれだけです。データならコンピューターでいろいろなことができます。

ハンス・ロスリングの講演を見た方はいますか。TED でも特に素晴らしい講演の 1 つなので、多いですね。国ごとに色を変え、所得水準と乳児死亡率を示し、時間とともに動かすデモをしました。データを集めたそのデモは、発展途上国の経済に関する多くの誤解を覆しました。こんなスライドの下には、すべてのデータがあるのです。

データは茶色くて四角くて退屈、などという印象でしょうか（？）。単独では自然に使えないからです。でも実際には、生活の多くがデータによって動いています。誰かがデータを取り出し、何かをするからです。ハンスは国連のさまざまなサイトなどから集めたデータを組み合わせ、元より面白いものにしました。そして、確か最初は Sun が開発したソフトウェアに入れ、見事なデモを作りました。

ハンスは大量のデータがとても重要だと強調しました。昨夜の集まりでもなお、同じことを力強く語っていたのがうれしかった。

### Linked Data の原則

2 つのデータをつなぐだけでも、彼のように 6 つをつなぐだけでもなく、誰もがデータを Web に載せ、想像できるほぼあらゆるものがそこにある世界を考えてください。私はこれを Linked Data と呼びます。その技術は非常に単純です。

Web に載せるときのルールは 3 つあります。まず、`http:` で始まる HTTP の名前を、文書だけでなく、文書が扱う物事にも使います。人、場所、製品、出来事、あらゆる概念的な物事が、`http` で始まる名前を持つのです。

第 2 に、その HTTP の名前に対して HTTP プロトコルで Web から取得すると、標準形式のデータが返ります。その物事や出来事の重要な情報、参加者、人の出生地などです。つまり、重要な情報を得られることが第 2 のルールです。

第 3 に、得られる情報は身長、体重、誕生日だけでなく、関係を持ちます。データとは関係なのです。ある人がベルリンで生まれ、ベルリンがドイツにある。その関係の表現が何であれ、関連先にも `http` で始まる名前があり、その先も調べられます。

人を調べ、出生した都市を調べ、その地域、町、人口などをたどれます。それが Linked Data です。数年前に「Linked Data」という文章を書いてから、動きが始まりました。ハンスの持っていたようなデータの箱が次々と増えていきます。単に 1 本の植物を支える根ではありません。

どんな植物であれ、つまりデモ、分析、データ内のパターン探しであれ、すべてのデータを見て結び付けられます。データは、つなぐものが増えるほど強力になるのです。

### 実際に動き始めた DBpedia

考えが広まり、ベルリン自由大学のクリス・バイザーが早くから面白いものを公開しました。オンライン百科事典 Wikipedia の大量の文書には、小さな情報ボックスがあり、そこにデータがあることに着目したのです。

Wikipedia からデータを抽出し、Web 上の Linked Data の塊にするプログラムを書き、dbpedia と名付けました。スライド中央の青い塊が Dbpedia です。ベルリンを調べると、ほかのデータの塊にもベルリンの情報があり、互いにつながっています。dbpedia からベルリンのデータを取り出せば、それらにもたどり着きます。成長し始めたことが刺激的なのです。これも草の根運動です。

ではデータについて考えましょう（？？）。データには非常に多くの形があります。Web の多様性を考えてください。いろいろなデータを載せられることが大切です。政府、企業、科学、個人、天気、出来事、講演、ニュースなどのデータがあります。多様性と未活用の可能性を感じてもらうため、いくつか紹介します。

### 政府データ

バラク・オバマは演説で、米国政府のデータをアクセス可能な形式でインターネット上に公開すると述べました。Linked Data として公開してほしいと思います。透明性だけのためではありません。政府の透明性は大切ですが、あらゆる省庁のデータには、米国人の生活に関する情報が大量に含まれています。役に立ち、価値があります。会社で使うことも、子どもが宿題に使うこともできます。提供することで世界をよりよく動かせるのです。

### 「生データを今すぐ」と求めよう

政府のデータを担当していたり、その所在を知っていたりすると、担当者がデータベースを抱え込みたくなることに気付きます。立派なサイトを作るまでは手放さないのです。もちろん立派なサイトを作ってください。それを否定するつもりはありません。でも、その前に未加工のデータをください。私たちはデータ、生のデータが欲しいのです。

「生データを今すぐ」と求めなければなりません。練習しましょう。「生の」「データを」「今すぐ」と言えますか。そう、「生データを今すぐ」です。練習は大切です。納税者として既に対価を払ったデータであっても、渡さずに持ち続ける口実はいくらでも出てくるからです。米国だけの話ではなく、企業でも同じです。

### 科学データ

ほかのデータ源も紹介します。TED の私たちは、人類の大きな課題をよく知っています。がんを治すこと、アルツハイマー病の脳を理解すること、経済を理解して安定させること、世界の仕組みを理解すること。科学者は確かな考えを抱き、それを Web で伝えようとしています。でも現在の知識の多くはデータベースに、しばしば各自のコンピューターにあり、共有されていません。

例えばアルツハイマー病の研究や創薬では、Linked Data が大量に現れ始めています。科学者が情報の孤島を抜け出すよい方法だと気付いたからです。ゲノム情報はある建物のデータベースに、タンパク質の情報は別の場所にありました。今、それらを Linked Data として結び付けています。「シグナル伝達に関与し、かつ錐体ニューロンと関連するタンパク質はどれか」という、私たちなら尋ねないような問いを立てられるのです。

その問い（？？）を Google に入れても、以前に誰も尋ねていないので答えるページはありません。223,000 件見つかっても使える結果はありません。結び付けた Linked Data なら 32 件、それぞれ該当するタンパク質を調べられます。分野をまたぐ問いを科学者が立てられることは、まったくの（？？）変化です。とても重要です。科学者はまったく（？？）そこにいる時期（？）です。他の科学者が集めたデータの力は閉じ込められており、大きな問題を解くために解放する必要があります。

### 個人データ

ここまででは、データは大機関から来るもので自分には関係ないと思うかもしれません。しかし、データは私たちの生活に関わります。好きなソーシャルネットワークにログインし、「この人は友達」とすると、*チン*、関係、つまりデータです。「この写真はこの人を写している」とすると、それもデータです。

サイトで何かをするたび、サイトはデータを集め、使い、再利用して、ほかの人の利用を面白くします。でも旅行の Linked Data サイトで、「この写真をあのグループ全員に送りたい」と思っても、壁を越えられません。Economist の記事や多くのブログでも論じられた、大きなもどかしさです。孤島をなくし、ソーシャルネットワーク間の相互運用性を実現するため、Linked Data が必要です。

### OpenStreetMap

最後のデータは、最もわくわくするものかもしれません。来場前に OpenStreetMap を見ました。地図ですが Wiki でもあります。拡大すると、今いるテラス劇場がありましたが、名前がありませんでした。編集モードで劇場を選び、下に名前を追加して保存できます。今 openstreetmap.org でこの場所を見れば、劇場に名前が付いています。私が今やったのです。皆が少しずつ貢献すれば、ほかの人も自分の分を担うことで、信じられないほどの資源ができるのです。

### これが Linked Data の意味

皆が少しずつ作業し、それらがつながること。これが Linked Data の仕組みです。あなたが少し行い、ほかの人も行う。自分で公開するデータは多くなくても、データを求めることはできます。練習もしました。Linked Data は巨大で、今日話したのはごく一部です。生活、仕事、遊びのあらゆる側面にデータがあります。データ源の数だけの話ではありません。結び付けることで、文書を介した Web だけでは得られない、実に大きな力を得られるのです。

今は、私たちが行動しなければならない段階です。よい考えだと思った人が取り組む必要があります。TED には、すぐに投資対効果が得られなくても、皆が取り組めばよい結果になるからと行動する人がたくさんいると思います。それが Linked Data です。ぜひ実行し、データを求めてください。広める価値のある考えだと思います。ありがとう。
