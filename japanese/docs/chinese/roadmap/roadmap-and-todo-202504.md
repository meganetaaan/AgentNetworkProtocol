<a id="协议完善"></a>
## プロトコルの改善

<a id="智能体身份"></a>
### エージェントのアイデンティティ

- [ ] 利用者とエージェント提供者の間、利用者のエージェントとサービスのエージェントの間など、エージェントのアイデンティティに関する権利・責任の境界を確定する。全体として「リクエスト即認可、署名即証明」の原則に従う
- [ ] アイデンティティのプライバシー保護について、サブDIDのライフサイクルをどう管理するか、破棄する場合、その後のアフターサービスの問題をどう処理するか、などを確定する
- [ ] 成年か、学歴が要件を満たすか、といった利用者の身元情報をどう検証するか、その流れをどう設計するかを検討する（W3Cの検証可能クレデンシャル仕様を利用する可能性がある）

<a id="智能体描述"></a>
### エージェントの記述

- [ ] エージェントの記述に、新しいJSON-LDフィールドの定義説明を追加し、関連フィールドのWebページを公開する
- [ ] 双方向のやり取りを充実させる。エージェントAがBにリクエストを送った後、Bが非同期で応答を送る方法を検討する
- [ ] json-rpc、websocket、wot、音声・動画プロトコルなど、他のプロトコルとの互換性の方式を検討する
- [ ] エージェントの記述文書に認証が必要かを検討する（必要な場合、特に複数の認証方式があると、衝突が生じる可能性がある）
- [ ] エージェントの記述文書で、複数の認証方式をサポートする方法を検討する

<a id="智能体支付"></a>
### エージェントの決済

- [ ] エージェント間の決済操作をどう行うか、Alipay、WeChatなどの既存決済プラットフォームや国際決済経路にどう接続するか、同時に決済の安全性をどう確保するかを検討する
- [ ] 取引の証憑をどう保存するか、公証やアフターサービス処理の根拠として第三者のエージェントサービスに保存するかを検討する

<a id="智能体应用协议管理"></a>
### エージェントのアプリケーションプロトコル管理

- [ ] URIでAPIを特定できるようにする。例えばエージェントの記述でURIをAPIのidにすれば、モデルはAPI説明文書をダウンロードせず、事前学習のデータに基づいてAPIを直接呼び出せる
- [ ] 事前定義したプロトコルやAPIをクラウドにどう保存するか、どこに保存するか、どうアクセスするかを検討する
- [ ] 事前定義したAPIに対応するコードをどう生成・ダウンロードするか、コードの安全性をどう確保するかを検討する
- [ ] 事前定義したAPIをどう生成するかを検討する。二つのエージェントが自分たちで交渉して生成・アップロードすることを認めるか、それをどう動機付けるかを考える

<a id="智能体端到端加密"></a>
### エージェントのエンドツーエンド暗号化

- [ ] 既存のエンドツーエンド暗号化方式を変更し、did:wbaに基づいて再実装する（変更は大きくない）
- [ ] エンドツーエンド暗号化の利用場面を説明する文書を整理する。リバースプロキシ、すなわちエージェントがホスティングプラットフォームに登録し、プラットフォームがそのエージェント用の対外サービスエンドポイントを開く場面である。この用途では、エージェント間の通信内容をホスティングプラットフォームに取得されないよう、エンドツーエンド暗号化が必要になる
- [ ] リバースプロキシ方式で、エージェントの記述やAPIへのリクエストなどの操作をどう行うかを検討する

<a id="anp开源软件完善"></a>
## ANPオープンソースソフトウェアの改善

<a id="agent-connect"></a>
### Agent Connect

- [ ] SDKのコード利用例を充実させる。現在は古いdid:allに属する例が多いため、更新が必要
- [ ] Agent Connectを改善する。生成するdid文書に文書全体への署名フィールドを含め、安全性を高める
- [ ] ruffを使ってコード検査とコード整形を行う

<a id="anp-server"></a>
### ANP Server

- [ ] DID管理、エージェントの記述、エージェントの発見、エージェントのclientなど、ANPの主要機能と主要モジュールを含むオープンソースのANP serverを実装する。ANP serverを基盤に、ANP対応エージェントを容易に構築できるようにする

<a id="anp-command-line-tool"></a>
### ANP Command Line Tool

- [ ] ANPコマンドラインツールを改善し、DID、秘密鍵、DID文書を生成できるようにする
- [ ] ANPコマンドラインツールを改善し、モデルを呼び出し、記述文書やデータから仕様に適合するjson-ldデータを生成できるようにする

<a id="测试工具"></a>
### テストツール

- [ ] ANPテストツールを改善する。開始側として、受信側のANPプロトコルが正常かを検証する
- [ ] ANPテストツールを改善する。受信側として、開始側のANPプロトコルが正常かを検証する
